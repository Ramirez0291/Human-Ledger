# Human Ledger

[中文](README.md) | **日本語** | [English](README.en.md)

家計簿をつけるのは良い習慣。でも、続けるのは大変です。Human Ledger は、その大変な部分をなくすためのアプリです。

自分の PC やサーバーで動かす、家族向けの家計簿 Web アプリです。日本で暮らす人向けで、金額はすべて日本円で管理します。

## 解決すること

| 困りごと | Human Ledger では |
|----------|-------------------|
| 1 件ずつ手入力するのがつらい | 銀行・クレジットカード・PayPay の明細をそのまま取り込み、数百件を一度に記帳 |
| 過去の支出をさかのぼって記録するのがつらい | 数か月〜数年分の CSV をまとめて取り込み。重複は自動で除外され、同じファイルを二度取り込んでも二重計上されません |
| 支出の分類や分析が面倒 | 日本の主要店舗を収録した辞書で自動分類。1 件直せば同じ店の他の明細にも反映。推移・カテゴリ・店舗別のレポートを自動作成 |
| 個人のお金のデータをクラウドに預けるのが不安 | 自分の環境で動かすので、データは手元のマシンにだけ保存され、外部には送信されません |
| 家族で家計簿を共有するのが面倒 | 家族それぞれがアカウントを作成し、1 台のサーバーでそれぞれ独立した家計簿を使えます |

自動認識できる明細：三井住友銀行・三井住友カード・楽天カード・PayPay の CSV。アプリのスクリーンショットに写っている文字を貼り付けて取り込むこともできます。画面は中文・日本語・English に対応しています。

## 使い方

[Docker](https://docs.docker.com/get-docker/) をインストールしておいてください。

```bash
git clone https://github.com/Ramirez0291/Human-Ledger.git
cd Human-Ledger
docker compose up -d
```

起動したら、ブラウザで `http://<このマシンの IP>:8000` を開きます（同じマシンからなら http://localhost:8000）。

- 最初にアクセスした人が、画面の案内に従ってユーザー名とパスワードを設定します。
- ほかの家族は同じアドレスで「新規登録」から、それぞれ自分の家計簿を作れます。
- このマシンにアクセスできれば、スマホ・タブレット・PC のブラウザから使えます。

**データはすべて `data/` フォルダにあります。** このフォルダをバックアップすれば家計簿全体のバックアップになります。アプリの「設定 → バックアップとエクスポート」からもダウンロードできます。

### よく使う設定

`.env.example` を `.env` にコピーして編集し、`docker compose up -d` で反映します。

- `ALLOW_REGISTRATION=false`：家族全員の登録が済んだら新規登録を停止
- `PORT=8000`：公開ポートを変更
- `COOKIE_SECURE=true`：HTTPS でアクセスする場合に有効化

### アップデート

```bash
git pull
docker compose up -d --build
```

データベースは起動時に自動で更新されます。

### バックアップから復元

バックアップの zip を `data/` フォルダに置いてから：

```bash
docker compose stop
docker compose run --rm --entrypoint python -w /app/backend app scripts/restore_backup.py /app/data/バックアップファイル名.zip
docker compose start
```

元のデータは `*.bak-日時` という名前で残ります。
